# Super Kart 8 · 超级卡丁车 8

浏览器 3D 卡丁车竞速：4 个杯赛 / 20 条赛道 / 8 人联机，全程序化生成，零外部素材。

- **入口**：`index.html`，所有资源用相对路径引用，静态托管即可。
- **单机**：打开即玩，无需登录、无需联网、无需构建。
- **联机**：登录只在 WorkBuddy 云服务注册域名下可用；本镜像站点会自动把登录入口指向官方站点，
  不会白点一次。想体验多人可在地址后加 `?lan=1`（同浏览器多标签演示）。
- **键位**：WASD / 方向键转向与油门，空格漂移，Shift 用道具，P 暂停（暂停面板有完整键位表）。

> 本目录未注入游戏厅的 `arcade.js` 账号 / 防沉迷守卫，避免与卡丁车自身的联机登录冲突。
> 若需要纳入游戏厅门禁，在 `index.html` 顶部按根目录 README 的说明补三行脚本即可。

根目录 README 的「新增游戏」章节记录了本条目的维护方式。
