# 🌾 星野物语 (Starfield Story)

一个**完全自由的像素沙盒生活 RPG** —— 种田、打怪、养家、探索，没有任何线性强制流程。

> 所有美术（角色、作物、怪物、建筑、地形、物品图标）和音乐音效都是**代码程序化生成**的，不依赖任何外部图片或音频资源。

---

## ▶ 运行方式

直接用浏览器打开 `index.html` 即可。无任何依赖。

> 💡 **在 DSH 预览窗口（iframe）中运行**：游戏已针对 iframe 环境做了专门适配——
> 包括画布尺寸为 0 时自动兜底、`requestAnimationFrame` 被节流时用定时器保底刷新、
> 进入游戏时立即重绘等。若预览面板第一次打开时画面未出现，点一下面板内的
>「新的开始」按钮、或刷新一下预览即可正常显示。

如果想用本地服务器（推荐，避免个别浏览器的文件协议限制）：

```bash
cd 星野物语
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 🌱 核心玩法

### 农场生活
- 用**锄头**耕地 → 选中**种子**播种 → 用**洒水壶**浇水。
- 作物按现实游戏天数生长（每天自动推进），不同作物有各自的适种季节与生长周期。
- 番茄、玉米、草莓、蓝莓收获后可以**自动再生**。
- 小麦可以做面包，草莓可以做蛋糕，作物还能卖钱。
- 冬天需要在室内或温室（计划中）躲避严寒。

### 战斗与探索
- 夜晚和矿洞里会刷新史莱姆、蝙蝠、骷髅、幽灵、火焰小鬼等怪物。
- 武器有铁剑、精钢剑、符文之刃和远程弹弓，暴击与战斗技能等级挂钩。
- **幽暗矿洞共 5 层**，越深矿石越珍贵，B3 有石魔像，B5 有隐藏 Boss「虚空领主」。
- 采集铜、铁、银、金、棱镜碎片等矿石，用于打造装备和戒指。
- 击杀怪物会掉落素材、金币与经验，还有几率掉落稀有材料。

### 社交与家庭
- 8 位村民，各有职业、喜好、日程与对话。
- 每天对话增加好感，赠送对方喜欢的礼物可通过**5 颗心**。
- 好感达到 **3 颗心（60 点）** 后，选中**戒指**使用即可**求婚结婚**。
- 可以花 500 G 领养小狗、小猫或小鸟，宠物会跟随你。

### 技能成长
- 六大技能：**农耕 / 战斗 / 采矿 / 钓鱼 / 采集 / 烹饪**。
- 每项技能独立升级，等级影响产量、暴击、配方解锁。
- 玩家等级提升会增加生命、魔力与体力上限。

### 四季与天气
- 28 天一个月，春夏秋冬循环，草地和森林会随季节变色。
- 晴、多云、雨、雷雨、雪、雾六种天气，配有雨滴、雪花、雷闪粒子效果。
- 昼夜循环，夜晚需要火把光照（角色自带微光），画面会变暗。

### 任务系统
- 12 个可接取任务，涵盖社交、种田、钓鱼、战斗、挖矿、烹饪、结婚等。
- 任务追踪器常驻显示，完成后自动发放奖励。

## 💾 存档

- 自动存档：每 60 秒 / 每天开始 / 暂停时。
- 手动存档：设置面板 → 「立即存档」。
- 存档保存在浏览器 `localStorage` 中（key: `starfield_save`）。
- 标题画面点「继续游戏」即可读取。

## 📁 代码结构

```
星野物语/
├── index.html          # 页面骨架与 UI 布局
├── css/style.css       # 像素风 UI 样式
└── js/
    ├── utils.js        # 工具函数、随机数、噪声、常量
    ├── audio.js        # WebAudio 程序化音效与背景音乐
    ├── items.js        # 物品 / 作物 / 配方 / 怪物 / 村民数据库
    ├── world.js        # 地图生成（村庄、农场、矿洞、四季）
    ├── entities.js     # 玩家 / 怪物 / NPC / 宠物 / 粒子 / 抛射物
    ├── systems.js      # 农业 / 战斗 / 钓鱼 / 制作 / 社交 / 任务 / 时间
    ├── render.js       # 程序化像素贴图、地形、光照、天气渲染
    ├── input.js        # 键鼠输入处理
    ├── ui.js           # HUD / 背包 / 制作 / 社交 / 任务 / 商店 / 地图
    └── game.js         # 主循环、场景管理、存档
```

## ✨ 特色

- **零素材依赖**：所有像素画都是运行时用 Canvas API 一个个像素画出来的。
- **零音频依赖**：背景音乐与 20+ 种音效全部由 WebAudio 振荡器实时合成。
- **高自由度**：没有必须完成的主线，想种田就种田，想打 Boss 就打 Boss，想谈恋爱就谈恋爱。
- **完整生活循环**：种地 → 收获 → 出售 → 买种子/装备 → 下矿 → 打造 → 战斗 → 恋爱 → 结婚。

祝你玩得开心，在星野村书写属于你的故事！🌟
