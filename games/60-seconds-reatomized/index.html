01

GET STARTED

从这里开始

下载后，把运行包移到 UOS 电脑，在终端依次完成下面的步骤。

1

解压运行包

进入下载文件所在目录，解压后进入游戏文件夹。

tar -xzf 60-seconds-uos-arm64-compat.tar.gz
cd 60-seconds-linux
2

检查 UOS 环境

无需 sudo。检查脚本会记录系统版本、显示会话和已有 Android 运行环境。

bash uos-check.sh > uos-check.txt 2>&1

首次使用时先查看 uos-check.txt，确认 Android 环境已经就绪。

3

安装并启动

Waydroid 容器和桌面会话运行后，以普通桌面用户执行：

bash run.sh check
bash run.sh

如果使用 UOS 自带的其他 Android 应用环境，可从该环境导入包内的 game.apk。

Android 环境

桌面与依赖

Waydroid 需要可用的 Wayland、Binder 支持及图形环境；助手需要 Python 3。

当前 UOS 使用 X11 桌面怎么办？

Waydroid 的窗口集成需要 Wayland。可使用设备支持的 Wayland 会话，或评估 Weston 嵌套窗口方案。具体方式取决于 UOS 版本和 GPU，请先查看环境检查结果；完整说明中提供了适用条件。
